# MCP Description Specification — v0.7.0 (current stable release)

Version **0.7.0** is the current stable release of the MCP Description
specification. Its canonical, normative source is **not** stored in this
repository; it is maintained on Cisco Open.

- Canonical specification text and reference tooling (`mcpcontract`):
  [`cisco-open/mcptoolkit-contract`](https://github.com/cisco-open/mcptoolkit-contract/tree/main/spec)
- Versioned JSON Schema (mirrored here for validation):
  [`../../schemas/mcp-description/0.7.0.json`](../../schemas/mcp-description/0.7.0.json)

This folder intentionally contains only this pointer. The specification text
for 0.7.0 is deliberately not copied here to avoid forking the canonical
source located at Cisco Open. For the in-progress draft, see [`../draft/`](../draft/).

See [`../../specification-status.json`](../../specification-status.json) for the
machine-readable release status.
