## Classification vocabulary

- **Normative** — requires MCP Description specification and schema changes.
- **Documentation** — compatible clarification or terminology update.
- **Extension/future work** — should be handled outside the v0.8.0 core or deferred.
- **Toolkit-only** — affects `mcpcontract` or another implementation but not the format.
- **No impact** — runtime protocol change that a static description need not represent.
