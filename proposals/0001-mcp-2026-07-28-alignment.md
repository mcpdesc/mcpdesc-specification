# Proposal 0001: Align MCP Description with MCP 2026-07-28

- Status: Draft
- Author(s): `{mcpdesc}` contributors
- Created: 2026-07-28
- Target version: 0.8.0
- Historical input: https://github.com/mcpdesc/mcpdesc.org/issues/8

## Summary

Assess the MCP protocol release dated 2026-07-28 and update MCP Description only where a static server description requires new or changed semantics.

## Problem

MCP Description v0.7.0 predates the MCP 2026-07-28 protocol release. The protocol introduces breaking and additive changes, but not every runtime change belongs in a static description format. A deliberate impact analysis is required before editing the schema.

## Goals

- Identify protocol changes that affect static server descriptions.
- Preserve v0.7.0 documents wherever reasonable.
- Align terminology and referenced MCP structures with the final protocol.
- Document toolkit-only or runtime-only impacts without adding unnecessary fields.

## Non-goals

- Reimplement the MCP protocol.
- Mirror every JSON-RPC request or result shape.
- Modify the MCP Toolkit in this repository.
- Automatically adopt every MCP extension into the core description schema.

## Required analysis

Complete `planning/mcp-2026-07-28-impact-matrix.md` using primary MCP sources. Classify each change as normative, documentation-only, extension/future work, toolkit-only, or no impact.

## Compatibility

To be completed after the impact matrix. Any change that invalidates a conforming v0.7.0 document requires explicit approval and migration guidance.

## Security and privacy considerations

Assess authorization metadata, `_meta`, trace context, extension declarations, and any information that a static description might expose.

## Open questions

- Which MCP protocol version or range should a description declare, if any?
- How should official MCP extensions be represented without coupling their lifecycle to the core MCP Description version?
- Which deprecated MCP features remain describable during their deprecation window?
- Does the new discovery model alter the purpose or terminology of MCP Description?
